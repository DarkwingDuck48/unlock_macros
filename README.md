# unlock-macro

CLI-утилита для просмотра, снятия и сброса пароля **«Lock project for viewing»**
в VBA-проектах Excel. Реализация формата защиты VBA-проекта по спецификации
[MS-OVBA] §2.4.3 и §2.4.4 на Rust.

## Назначение и правомерное использование

Утилита предназначена для работы с файлами, **которыми вы владеете или вправе
распоряжаться** — например, с собственными шаблонами и макросами либо с файлами
в инфраструктуре вашей организации, поддержку которых вы ведёте. Типичный
сценарий: забыт пароль на просмотр кода в собственном проекте, и нужно вернуть
к нему доступ.

Пароль «Lock project for viewing» — это защита пользовательского интерфейса
редактора VBA, **а не шифрование**: он хранится в виде одностороннего хеша SHA-1
и не расшифровывается. Утилита восстанавливает доступ к _своему_ проекту, но не
вскрывает постороннюю криптографическую защиту.

**Не используйте** утилиту для доступа к файлам, на которые у вас нет прав.
Авторы не несут ответственности за применение вопреки применимому
законодательству, условиям лицензий или политикам организации.

## Поддерживаемые контейнеры

- OOXML: `.xlsb`, `.xlsm`, `.xlam`, `.docm`, `.pptm`, `.docx`/`.pptx` с макросами;
- легаси OLE: `.xls`, `.doc`, `.ppt`;
- одиночный `vbaProject.bin`.

## Как это работает

Значения `CMG`/`DPB`/`GC` перекодируются **байт-в-байт той же длины**, поэтому
структура контейнера не перестраивается. Исходный файл никогда не изменяется —
результат пишется в новый файл.

## Требования

- Windows — VBA-проекты и редактор макросов существуют только в Office для Windows.
- Rust 1.88+ (edition 2024).

## Сборка

```bash
cargo build --release
```

Бинарник: `target/release/unlock-macro.exe`.

## Использование

### Показать состояние защиты

```bash
unlock-macro info book.xlsb
```

Выводит расшифрованные `CMG`/`DPB`/`GC`, состояние (`no-password` / `hash` /
`plaintext`), а для варианта `hash` — соль и SHA-1-хеш.

### Снять защиту (проект открывается без пароля)

```bash
unlock-macro unlock book.xlsb
unlock-macro unlock book.xlsb -o out.xlsb
unlock-macro unlock vbaProject.bin -o vbaProject_unlocked.bin
```

По умолчанию результат пишется рядом с исходным файлом как
`<имя> (unlocked)<расширение>`.

### Оставить защиту, но сбросить пароль

```bash
unlock-macro setpass book.xlsb -p s3cr3t
unlock-macro setpass book.xlsb -p пароль --codepage cp1251 -o out.xlsb
```

### Проверить реализацию

```bash
unlock-macro selftest
```

Проверяет расшифровку на эталонном примере [MS-OVBA] §3.1.6 и круговой тест
хеша пароля.

## Параметры

| Параметр           | Описание                                                     |
| ------------------ | ------------------------------------------------------------ |
| `-o`, `--out`      | выходной файл (по умолчанию `<имя> (unlocked)<расширение>`)  |
| `-p`, `--password` | новый пароль (`setpass`)                                     |
| `--codepage`       | кодировка пароля: `cp1251` (по умолчанию), `cp1252`, `utf-8` |
